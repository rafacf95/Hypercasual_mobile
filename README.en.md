# Hypercasua Mobile Game project

This repository is a hypercasual mobile game project developed using the **Unity Engine**.  
It was created with a focus on learning and practicing mobile game development, exploring simple mechanics, intuitive controls, and fast gameplay loops.

## Overview

The game follows the classic hypercasual concept, where the player must react quickly to the challenges presented on screen, aiming to achieve the highest possible score.

### Main Features

- Simple and intuitive gameplay mechanics  
- Basic scoring system  
- Controls adapted for mobile devices (touchscreen)  
- Organized project structure following Unity standards  

## Technologies and Tools

- Game Engine: Unity  
- Programming Language: C#  
- Git for version control  

## How to Download and Run

1. Clone the repository:

   ```bash
   git clone https://github.com/rafacf95/Hypercasual_mobile_game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Hypercasual_mobile_game
   ```

3. Open the project in Unity Hub using the Unity version specified for the repository.

4. Press **Play** to run the game.
