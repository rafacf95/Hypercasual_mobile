# HypercasualMobileGame

Este repositório é um projeto de jogo mobile no gênero hypercasual desenvolvido utilizando a **Unity Engine**.  
Foi criado com foco em aprendizado e prática de desenvolvimento de jogos mobile, explorando mecânicas simples, controles intuitivos e ciclos rápidos de gameplay.

## Visão Geral

O jogo segue o conceito clássico de jogos hypercasual, onde o jogador precisa reagir rapidamente aos desafios apresentados na tela, buscando a maior pontuação possível.

### Características Principais

- Mecânica de jogo simples e intuitiva  
- Sistema básico de pontuação  
- Controle adaptado para dispositivos móveis (touchscreen)  
- Estrutura de projeto organizada seguindo padrões da Unity  

## Tecnologias e Ferramentas Utilizadas

-   Motor de jogo: Unity
-   Linguagem: C#
-   Git para controle de versão

## Como Baixar e Executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/rafacf95/Hypercasual_mobile_game.git
   ```

2.  Acesse o diretório do projeto:

    ``` bash
    cd Hypercasual_mobile_game
    ```

3.  Abra o projeto no Unity Hub utilizando a versão correspondente à do repositório.

4.  Pressione **Play** para rodar o jogo.
